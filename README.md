ATM Interface 

A secure and fully functional ATM Interface simulation built using Java. This object-oriented application models real-world banking operations, providing a user-friendly command-line interface for account management.

 Features
• Check Balance: Instantly retrieve and display the current account balance.
•  Deposit Funds: Safely add money to the account balance with instant updates.
• Withdraw Cash: Securely deduct funds after verifying sufficient balance limits.
•  Transaction Security: Implements validation to ensure valid inputs and prevent overdrafts.

Technologies Used
• Language: Java (JDK 11+)
• Core Concepts: Object-Oriented Programming (OOP) - Classes, Objects, Encapsulation.
